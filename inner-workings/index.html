Inner Workings

Short animated explainers of how everyday machines work: locks, valves, gears, switches and the systems around you. Every Short is drawn in code and narrated by a calm synthetic voice.

Inner Workings is an AI-assisted animation channel on YouTube. A small private tool uses the YouTube Data API to upload the channel's own videos and the YouTube Analytics API to read the channel's own statistics.
